This version uses a different picture for each major website title/category:

Medical Equipment  -> equipment-category.jpg
Accessories        -> accessories.jpg
Consumables        -> consumables.jpg
Medical Batteries  -> batteries.jpg
Service            -> service.jpg

The images are included both at the website root and under assets/images/
for easy future replacement.

To replace any picture later:
1. Prepare a JPG image.
2. Rename it exactly to the corresponding filename above.
3. Replace that file in the GitHub repository root.
4. Commit the change and wait for GitHub Pages to redeploy.
5. Refresh bareeqnajd.com using Ctrl + Shift + R.
