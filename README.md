# Bareeq Najd Medical Foundation - Complete GitHub Pages Website
Domain: bareeqnajd.com

This is a portable full static website package for another computer.

PUBLISH:
1. Extract this ZIP.
2. Open index.html locally to preview.
3. Upload ALL extracted files/folders directly to the GitHub repository root.
4. Commit to main.
5. GitHub Settings > Pages > Deploy from a branch > main > /(root).
6. Custom domain: bareeqnajd.com.

Includes root index.html, all website pages, local images/assets, official logo,
WhatsApp/email picture icons, .nojekyll, CNAME, robots.txt and sitemap.xml.
