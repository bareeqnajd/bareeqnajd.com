BAREEQ NAJD — FIXED PREMIUM GITHUB PAGES WEBSITE
================================================

This version is rebuilt specifically to prevent the issue where HTML loads but
the design and images do not appear.

WHY THIS VERSION IS MORE RELIABLE
- CSS is embedded directly in each HTML page.
- JavaScript is embedded directly in each HTML page.
- Main images are also copied to the repository root.
- Image links use simple names like logo.jpg and hero.jpg.
- CNAME is included for bareeqnajd.com.
- .nojekyll is included for GitHub Pages.

HOW TO UPLOAD
1. Extract this ZIP.
2. Open your GitHub repository.
3. Remove the old website files if you want to replace the current site.
4. Upload ALL extracted files directly into the repository root.
5. Do NOT upload the enclosing folder itself.
6. GitHub > Settings > Pages.
7. Choose Deploy from a branch > main > /(root).
8. Save and wait for deployment.
9. Open https://bareeqnajd.com
10. Press Ctrl + Shift + R to hard refresh.
