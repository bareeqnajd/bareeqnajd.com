HOW TO PUBLISH WITH GITHUB PAGES
1. Extract this ZIP.
2. Create a GitHub repository.
3. Upload ALL extracted files to the repository root.
4. In GitHub: Settings > Pages.
5. Under Build and deployment, select 'Deploy from a branch'.
6. Choose your main branch and / (root), then Save.
7. GitHub will publish the website.
8. For your custom domain, enter: bareeqnajd.com in GitHub Pages settings.
9. Add the DNS records GitHub requests in Porkbun.
